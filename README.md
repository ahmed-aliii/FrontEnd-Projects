# 🌐 Frontend Projects & Templates Collection

A curated collection of frontend projects and UI templates built with **HTML**, **CSS**, **JavaScript**, and **Bootstrap**. These projects demonstrate responsive design, interactive features, and clean UI/UX principles—great for learning, practicing, and showcasing frontend development skills.



## 🚀 Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Styling and layouts
- **JavaScript (Vanilla)** – Interactivity and DOM manipulation
- **Bootstrap 5** – Responsive design, components, and layout
